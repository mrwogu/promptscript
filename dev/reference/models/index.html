    Model Catalog¶

    PromptScript ships a catalog of Anthropic, OpenAI, Google, and xAI models. Agent model and specModel values and skill model values resolve against it, so you write a model once and each target gets the name it expects. PS041 uses the same catalog to report deprecated and retired models.

    This page is generated from the catalog source, so it matches what the compiler does. To use a model that is not listed yet, or to change a built-in profile, add it under models.profiles in promptscript.yaml. See Configuration: models.

    This version ships 58 profiles from 4 providers. They were last checked against the provider documentation on 2026-09-23.

    Model References¶

    A value matches a profile by profile id, alias, API id, or display name, ignoring case. claude-opus-5-5, opus-5.5, and Claude Opus 5.5 all select the same release. inherit keeps the model already selected in the tool.

    Names that are not in the catalog are written unchanged on every target, so gateway model ids, BYOK model ids, and Claude Code's opusplan keep working. The exception is a value the target spells its own way: GitHub Copilot writes auto as Auto.

    Floating Aliases¶

    A floating alias points at the newest release of its Claude family that is not retired. Claude Code and Grok Build write the alias as it is and pick the release themselves. Other targets get the current release from this table, so they move to a new release when you upgrade PromptScript and compile again. Use a profile id when an agent must stay on one release.

    Alias Family Current release Display name
    opus claude-opus claude-opus-5-5 Claude Opus 5.5
    sonnet claude-sonnet claude-sonnet-5 Claude Sonnet 5
    haiku claude-haiku claude-haiku-4-5 Claude Haiku 4.5
    fable claude-fable claude-fable-5-1 Claude Fable 5.1

    Target Model Names¶

    Every target with a native model field has its own naming rule. This table shows what each one writes for a few example values:

    Written in .prs Claude Code, Grok Build GitHub Copilot Factory AI Codex Cursor
    opus opus Claude Opus 5.5 claude-opus-5-5 omitted (PS4004) claude-opus-5-5
    sonnet sonnet Claude Sonnet 5 claude-sonnet-5 omitted (PS4004) claude-sonnet-5
    haiku haiku Claude Haiku 4.5 claude-haiku-4-5-20251001 omitted (PS4004) claude-haiku-4-5
    fable fable Claude Fable 5.1 claude-fable-5-1 omitted (PS4004) claude-fable-5-1
    inherit inherit omitted inherit omitted inherit
    claude-sonnet-4-5 claude-sonnet-4-5-20250929 Claude Sonnet 4.5 claude-sonnet-4-5-20250929 omitted (PS4004) claude-sonnet-4-5
    gpt-5.3-codex omitted (PS4004) GPT-5.3-Codex gpt-5.3-codex gpt-5.3-codex gpt-5.3-codex
    gemini-3.1-pro-preview omitted (PS4004) Gemini 3.1 Pro gemini-3.1-pro-preview omitted (PS4004) gemini-3.1-pro-preview
    • omitted means the output has no model field, so the tool uses its default model.
    • omitted (PS4004) means the target cannot run models from this provider. Compilation reports a PS4004 warning. To write a name anyway, set models.profiles.<id>.targets.<target> in promptscript.yaml.

    GitHub Copilot and Factory AI map specModel the same way. Claude Code and Grok Build also map the model field of skills, including a model written in the skill file's own frontmatter; a model set in .prs wins. The rules behind the table are listed in Configuration: target model names.

    Profiles¶

    Status Meaning
    current Recommended for new instructions
    legacy Still served, but a newer release replaces it
    deprecated The provider announced it will retire the model; PS041 warns
    retired The provider no longer serves the model; PS041 warns

    PS041 suggests a replacement by following the successor chain to a current release. Dates follow the provider API. A tool can stop offering a model before the provider retires it.
