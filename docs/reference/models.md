# Model Catalog

PromptScript ships a catalog of Anthropic, OpenAI, Google, and xAI models.
Agent `model` and `specModel` values and skill `model` values resolve against
it, so you write a model once and each target gets the name it expects. PS041
uses the same catalog to report deprecated and retired models.

This page is generated from the catalog source, so it matches what the
compiler does. To use a model that is not listed yet, or to change a built-in
profile, add it under `models.profiles` in `promptscript.yaml`. See
[Configuration: models](config.md#models).

## Model References

A value matches a profile by profile id, alias, API id, or display name,
ignoring case. `claude-opus-5-5`, `opus-5.5`, and `Claude Opus 5.5` all select
the same release. `inherit` keeps the model already selected in the tool.

Names that are not in the catalog are written unchanged on every target, so
gateway model ids, BYOK model ids, and Claude Code's `opusplan` keep working.
The exception is a value the target spells its own way: GitHub Copilot writes
`auto` as `Auto`.

## Floating Aliases

A floating alias points at the newest release of its Claude family that is
not retired. Claude Code and Grok Build write the alias as it is and pick the
release themselves. Other targets get the current release from this table, so
they move to a new release when you upgrade PromptScript and compile again.
Use a profile id when an agent must stay on one release.

- `omitted` means the output has no model field, so the tool uses its default
  model.
- `omitted (PS4004)` means the target cannot run models from this provider.
  Compilation reports a PS4004 warning. To write a name anyway, set
  `models.profiles.<id>.targets.<target>` in `promptscript.yaml`.

GitHub Copilot and Factory AI map `specModel` the same way. Claude Code and
Grok Build also map the `model` field of skills, including a model written in
the skill file's own frontmatter; a `model` set in `.prs` wins. The rules
behind the table are listed in
[Configuration: target model names](config.md#target-model-names).

| `retired`    | The provider no longer serves the model; PS041 warns         |

PS041 suggests a replacement by following the successor chain to a current
release. Dates follow the provider API. A tool can stop offering a model
before the provider retires it.
