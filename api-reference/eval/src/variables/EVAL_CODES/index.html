EVAL_CODES

PromptScript API

const EVAL_CODES: object

Defined in: eval/src/errors.ts:8

Codes of eval errors and findings: PS61xx datasets, PS62xx suites, PS63xx providers and the run, PS64xx cache, PS65xx cost, PS66xx judge, PS67xx reports and sample imports.
