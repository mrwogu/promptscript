GeminiFormatter

PromptScript API

Defined in: formatters/src/formatters/gemini.ts:62

Formatter for Gemini CLI instructions.

Gemini uses GEMINI.md as its main configuration file, .gemini/commands/.toml for commands (TOML format), and .gemini/skills//skill.md for skills (lowercase).

Gemini has no agent concept.

Supports three versions:

  • simple: Single GEMINI.md file
  • multifile: GEMINI.md + commands (TOML) + skills
  • full (default): Multifile + skills
