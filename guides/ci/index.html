CI/CD Integration

PromptScript creates prompt-as-code for your AI instructions. Like any code, it should be validated and tested in your Continuous Integration (CI) pipeline.

Overview

Integrating PromptScript into CI/CD provides:

  • Syntax Validation - Catch .prs file errors before merge
  • Drift Detection - Ensure compiled outputs are up-to-date
  • Registry Sync - Validate against latest registry standards
  • Change Tracking - Only run on relevant file changes
flowchart LR
    subgraph CI["CI Pipeline"]
        checkout["Checkout"]
        install["Install CLI"]
        validate["prs validate"]
        compile["prs compile"]
        diff["Check Drift"]
    end

    checkout --> install --> validate --> compile --> diff

    validate -->|"Errors"| fail["❌ Fail"]
    diff -->|"Uncommitted changes"| fail
    diff -->|"All synced"| pass["✅ Pass"]

Key Commands for CI

CommandPurposeExit Code
prs validateValidate syntax and structure0=pass, 1=error, 2=warning (with --strict)
prs validate --strictTreat warnings as errors0=pass, 1=error, 2=warning
prs validate --format jsonJSON output for parsingSame as above
prs compileCompile to all targets0=success, 1=error
prs compile --dry-runPreview without writing0=success, 1=error
prs checkCheck config and dependencies0=healthy, 1=issues
prs diff --allShow uncommitted changesAlways 0
prs diff --format jsonMachine-readable diff report0=report produced, 1=error

Drift Check Without Writing Files

prs diff --format json reports the same drift without touching the working tree, which suits required checks on protected branches and jobs that post their findings elsewhere:

The command exits 0 for any valid report, including one with changes, so the job decides what counts as a failure. Reports follow the versioned diff schema: changes[] carries target, output path, change kind, ownership, and a sha256-<hex> content hash, unsupported[] repeats entries that the target cannot represent, and --include-content adds the generated content itself.

Troubleshooting

Common CI Issues

Error: Config file not found

Ensure promptscript.yaml exists in the repository root or specify path with --config.

Error: Registry authentication failed

Check that GITHUB_TOKEN or equivalent secret is set and has read access to the registry repository.

Error: Drift detected

Run prs compile locally and commit the generated files.

Error: Node.js version mismatch

PromptScript requires Node.js 20+. Update your CI configuration to use node:20 or higher.
