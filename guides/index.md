Start with product capabilities, then use the guides below for composition, governance, and

- [CI/CD Integration](https://getpromptscript.dev/guides/ci/index.md): Validate and test PromptScript files in your CI pipeline with GitHub Actions.

- [Migration](https://getpromptscript.dev/guides/migration/index.md): Migrate existing AI instructions from CLAUDE.md, .cursorrules, and other formats.
- [Security](https://getpromptscript.dev/guides/security/index.md): Security considerations for templates, external stacks, and best practices.
