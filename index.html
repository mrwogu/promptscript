The problem

AI instructions do not scale by copy-paste

Every AI tool wants its own file. Every repository keeps its own copy. Soon nobody knows which rules the agents actually follow.

Without PromptScript

  • A different file for every tool: CLAUDE.md, .cursor/rules, copilot-instructions.md, AGENTS.md
  • Copies drift apart across dozens of repositories
  • Company standards live in a wiki the agents never read
  • Third-party skills can carry hidden prompt injection
  • Switching AI tools means rewriting everything
→

With PromptScript

  • .prs sources inherited like code, native output for 50 agents
  • Company standards inherited by every repository, not copied
  • Changes reviewed in Git and validated in CI
  • Built-in security scanner for every prompt and imported skill
  • Add or switch tools by editing one target list

Prompts as code

Inherit, compose, and extend

Configuration is composable source, not copied text. Inherit a shared base, pass it arguments like a function, mix in reusable fragments, and override only what changes - with deterministic, reviewable merges.

project.prs source 
# IS-A: inherit a base, with arguments
@inherit @stacks/react-app(projectName: "Checkout", port: 8080)

# HAS-A: compose reusable fragments
@use @core/security
@use ./fragments/testing(framework: "vitest")

# override only what changes
@extend standards.code {
  framework: "react"
}

@extend restrictions {
  - "Use functional components only"
}
@inherit

Inherit a base

Single-parent "IS-A" chains from organization to team to project. Blocks merge with predictable rules.

@use

Compose fragments

Mix in multiple "HAS-A" capabilities like security or testing. Later imports win on conflicts.

params

Pass arguments like functions

A base declares typed parameters with defaults, like port: number = 3000, and uses them as {{projectName}}.

@extend

Extend and override

Patch specific paths, append or negate references, and seal properties that layers cannot change.

Built-in security scanner

Stop prompt injection before it ships

prs validate scans every instruction, skill, and imported file. Encoded payloads are decoded first, so hiding an attack in hex or Base64 does not get it through.

terminal output 
$ prs validate --strict
✖ Validation failed

✗ Blocked pattern detected:
  ignore\s+(all\s+)?previous\s+instructions
  at project.prs:8:1

✗ PS012: Malicious content detected
  in raw hex (spaced): Prompt injection
  Decoded: "IGNORE SAFETY RULES"
  at project.prs:16:14

✗ PS010: URL shortener detected:
  http://bit.ly/deploy-help
  at project.prs:16:14
PS005

Injection and overrides

Phrases like "ignore previous instructions" and fake authority overrides fail the build.

PS012

Encoded payloads

Base64, hex, URL encoding, HTML entities, ROT13, and more are decoded and checked.

PS014

Invisible Unicode

Right-to-left overrides, zero-width characters, and homoglyphs.

 PS010

Suspicious links

Plain HTTP, link shorteners, and credentials in URLs.
prs skills

Install skills like packages

Pull a skill from any Git repository or local folder. PromptScript validates it, pins the exact commit, and compiles it into the skill folder of every agent you use.

terminal output 
$ prs skills add github.com/anthropics/skills/skills/pdf
✔ Skill added
  ✓ @use github.com/anthropics/skills/skills/pdf
    Lockfile updated: promptscript.lock

$ prs compile
  ✓ .claude/skills/pdf/SKILL.md
  ✓ .github/skills/pdf/SKILL.md
  ✓ .github/skills/pdf/scripts/fill_fillable_fields.py
  ✓ .factory/skills/pdf/SKILL.md
✔ Compilation successful
add

From any Git repo or folder

HTTPS, SSH, or a local path. SKILL.md is checked against the Agent Skills spec before anything is written.

lock

Pinned and verified

The commit and a sha256 integrity hash go to promptscript.lock. Plain HTTP sources are rejected.

compile

Native in every agent

One skill, with its scripts and resources, lands in each agent's own skill folder.

update

Update or remove in one command

prs skills update refreshes lock entries, prs skills remove drops the import and its lock entry.

Skill composition

Build big skills from small, owned pieces

Split a complex skill into phases. Each phase is its own .prs file with its own context, parameters, and allowed tools, so different teams can own different parts.

ops.prs source 
@skills {
  ops: {
    description: "Production operations"

    # every phase is a separate .prs file
    @use ./phases/health-scan
    @use ./phases/triage(severity: "critical")
    @use ./phases/code-fix as autofix

    # shared phases from the Git registry
    @use @shared/phases/monitoring
  }
}
@use

Phases with boundaries

Each phase brings its own instructions and declares only the tools it needs.

 contracts

Typed inputs and outputs

Skills declare what they take and return, so they plug together cleanly.

 @extend

Extend without forking

Teams layer changes on a shared skill. Sealed properties stay locked.
Agents, MCP servers, and plugins

Build agent plugins once, ship everywhere

Describe MCP servers, specialized agents, and the plugin that bundles them in one file. Each target gets its own native MCP config, agent files, and plugin manifest.

incident.prs source 
@skills {
  triage: {
    description: "Classify incidents by severity"
  }
}

@mcpServers {
  observability: {
    transport: "http"
    url: "https://mcp.example.com/api"
  }
}

@agents {
  incident-responder: {
    description: "Investigate incidents"
    mcpServers: ["observability"]
    skills: ["triage"]
  }
}

@plugins {
  incident-suite: {
    version: "1.0.0"
    skills: ["triage"]
    mcpServers: ["observability"]
  }
}

Model mapping

Name a model once. Every tool gets its own spelling.

Each tool names models differently. Write opus or a full model id and PromptScript writes the name each target expects. When a target cannot run that model, the compiler warns (PS4004).

project.prs source 
@agents {
  reviewer: {
    description: "Review pull requests"
    model: "opus"
  }
}

FAQ

Questions teams ask first

What is PromptScript?

PromptScript is an open-source compiler for AI coding agent configuration. You write instructions, skills, agents, MCP servers, hooks, and plugins in .prs files, and it generates the native files for 50 tools, such as CLAUDE.md, .github/copilot-instructions.md, and Cursor rules.

Which AI coding tools does it support?

It compiles to 50 targets, including Claude Code, GitHub Copilot, Cursor, Codex, Gemini CLI, Windsurf, Factory AI, and OpenCode. Each target gets the file layout and format that tool reads.

How is it different from a shared AGENTS.md file?

AGENTS.md is one file that some tools read. PromptScript is the source behind it: it adds inheritance across repositories, parameters, skills, agents, MCP servers, validation, and a security scan, and it writes AGENTS.md together with the formats of every other tool.

Can I start from the instruction files I already have?

Yes. prs import converts an existing CLAUDE.md, Copilot, Cursor, or AGENTS.md file, prs migrate imports a whole project, and the built-in promptscript skill lets your AI agent do the migration for you.

How do teams share one configuration?

Publish a Git registry with prs registry init and prs registry publish, then inherit it in every project with @inherit. Remote imports are pinned by commit and sha256 hash in promptscript.lock, and prs vendor sync copies them for offline builds.

Does PromptScript send my prompts anywhere?

No. Compilation runs on your machine or in your CI. Anonymous usage telemetry is on by default and never includes source, prompts, compiled output, file paths, or project names. Turn it off with prs telemetry disable or DO_NOT_TRACK=1.

Is PromptScript free?

Yes. PromptScript is open source under the MIT license. The CLI is published on npm as @promptscript/cli.
