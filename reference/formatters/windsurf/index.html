Windsurf Formatter

View as Markdown

PromptScript compiles your .prs sources to native Windsurf configuration. The main output is .windsurf/rules/project.md. It is not enabled by default, add it to targets to use it.

Enable the Target

Pick an output version when you need more than the default:
