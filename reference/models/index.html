Model Catalog

View as Markdown

PromptScript ships a catalog of Anthropic, OpenAI, Google, and xAI models. Agent model and specModel values and skill model values resolve against it, so you write a model once and each target gets the name it expects. PS041 uses the same catalog to report deprecated and retired models.

This page is generated from the catalog source, so it matches what the compiler does. To use a model that is not listed yet, or to change a built-in profile, add it under models.profiles in promptscript.yaml. See Configuration: models.

This version ships 58 profiles from 4 providers. They were last checked against the provider documentation on 2026-09-23.

Model References

A value matches a profile by profile id, alias, API id, or display name, ignoring case. claude-opus-5-5, opus-5.5, and Claude Opus 5.5 all select the same release. inherit keeps the model already selected in the tool.

Names that are not in the catalog are written unchanged on every target, so gateway model ids, BYOK model ids, and Claude Code’s opusplan keep working. The exception is a value the target spells its own way: GitHub Copilot writes auto as Auto.

Floating Aliases

A floating alias points at the newest release of its Claude family that is not retired. Claude Code and Grok Build write the alias as it is and pick the release themselves. Other targets get the current release from this table, so they move to a new release when you upgrade PromptScript and compile again. Use a profile id when an agent must stay on one release.

Profiles

StatusMeaning
currentRecommended for new instructions
legacyStill served, but a newer release replaces it
deprecatedThe provider announced it will retire the model; PS041 warns

PS041 suggests a replacement by following the successor chain to a current release. Dates follow the provider API. A tool can stop offering a model before the provider retires it.
